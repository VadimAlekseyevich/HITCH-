# assets/

Non-code game assets will live here once needed.

For the MVP, art scope is intentionally minimal.

Early assets should exist only when they help evaluate:

- spatial readability;
- grapple targets;
- player readability;
- combat feedback;
- debugging.

Do not begin a production art pipeline before the core MVP hypothesis is validated.

Greybox geometry and temporary primitives are preferred during core movement/networking work.
