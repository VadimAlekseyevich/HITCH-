# Task 05 — Add 3D Debug Drawing Hooks

**Status:** PLANNED  
**Depends on:** Task 03

## Goal

Provide a tiny Godot-side debug drawing helper for frequently changing lines/vectors.

## Requirements

- use Godot `ImmediateMesh` for simple dynamic geometry;
- allow clearing and drawing colored line segments;
- keep it development-only in purpose;
- demonstrate it by drawing player forward and velocity vectors.

## Non-scope

- production VFX;
- retained debug-shape framework;
- arbitrary text labels in 3D.
